# Blender 5.2 PHD Architect

A Codex skill for governed Blender 5.2 work: topology readiness, rig construction, weights and correctives, animation authoring, and deterministic evidence. It applies to interactive Blender work and background-mode processes.

Install the folder as `blender-5-2-phd-architect` under your Codex skills directory, then invoke it with `$blender-5-2-phd-architect`.

The included scripts provide read-only `.blend` audits, standardized pose renders, and strict baseline/candidate comparisons with explicit expected rig/action additions.
